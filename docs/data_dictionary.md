## 字段详细说明

### 核心维度字段

#### school_id
- **类型**：INT
- **含义**：高校唯一标识，来自 gaokao.cn 的学校编码
- **示例值**：`10001`（北京大学）、`10003`（清华大学）
- **空值**：无空值
- **注意**：该 ID 与教育部学校代码不同，是 gaokao.cn 平台内部编码

#### province_id
- **类型**：STRING
- **含义**：生源省份代码，即考生所在省份
- **示例值**：`'11'`（北京）、`'44'`（广东）、`'31'`（上海）

### 专业信息字段

#### special_id
- **类型**：STRING
- **含义**：专业唯一标识（gaokao.cn 内部编码）
- **示例值**：`'1234567'`
- **空值**：少量为空字符串

#### sp_name
- **类型**：STRING
- **含义**：专业组名称（部分高校按专业组招生）
- **示例值**：`'理工类专业组一'`、`''`（不分组时为空）
- **空值**：约 40% 为空，不分专业组的高校此字段为空

#### spname
- **类型**：STRING
- **含义**：专业名称（核心字段）
- **示例值**：`'计算机科学与技术'`、`'临床医学（5年）'`、`'金融学'`
- **空值**：极少为空
- **注意**：同一专业在不同年份名称可能略有差异

#### info
- **类型**：STRING
- **含义**：专业附加信息，通常包含学制、学费等
- **示例值**：`'学制4年，学费5000元/年'`
- **空值**：约 60% 为空

#### remark
- **类型**：STRING
- **含义**：备注信息
- **示例值**：`'含实验班'`、`'中外合作办学'`
- **空值**：约 80% 为空

---

### 批次与招生类型字段

#### batch
- **类型**：STRING
- **含义**：录取批次代码
- **示例值**：`'1'`（本科一批）、`'2'`（本科二批）、`'B'`（提前批）
- **空值**：少量为空

#### local_batch_name
- **类型**：STRING
- **含义**：本地化批次名称，各省叫法不同
- **示例值**：`'本科一批'`、`'普通类提前批'`、`'本科批'`（新高考省份）
- **空值**：少量为空
- **注意**：新高考改革后部分省份合并批次，统称"本科批"

#### zslx_name
- **类型**：STRING
- **含义**：招生类型名称
- **示例值**：`'普通类'`、`'艺术类'`、`'体育类'`、`'保送生'`
- **空值**：少量为空

#### type
- **类型**：STRING
- **含义**：科类（文理分科省份适用）
- **示例值**：`'理科'`、`'文科'`、`'综合'`（新高考省份）
- **空值**：新高考省份此字段可能为空或"综合"

---

### 学科分类字段

#### level1_name
- **类型**：STRING
- **含义**：一级学科门类
- **示例值**：`'工学'`、`'理学'`、`'医学'`、`'经济学'`
- **空值**：约 20% 为空

#### level2_name
- **类型**：STRING
- **含义**：二级学科类别
- **示例值**：`'计算机类'`、`'电子信息类'`、`'临床医学类'`
- **空值**：约 20% 为空

#### level3_name
- **类型**：STRING
- **含义**：三级专业方向（更细分类）
- **示例值**：`'计算机科学与技术'`
- **空值**：约 50% 为空，粒度最细，覆盖率较低

---

### 录取分数字段

#### min_score
- **类型**：INT
- **含义**：最低录取分数（核心字段）
- **示例值**：`650`、`580`、`0`（数据缺失时为 0）
- **空值**：无空值，但 0 表示数据缺失
- **注意**：查询时建议加 `WHERE min_score > 0` 过滤无效数据

#### max_score
- **类型**：INT
- **含义**：最高录取分数
- **示例值**：`680`、`0`（数据缺失时为 0）
- **空值**：无空值，0 表示缺失
- **注意**：部分年份/省份不提供最高分，为 0

#### average_score
- **类型**：INT
- **含义**：平均录取分数
- **示例值**：`660`、`0`（数据缺失时为 0）
- **空值**：无空值，0 表示缺失
- **注意**：覆盖率低于最低分，约 40% 为 0

#### min_rank
- **类型**：INT
- **含义**：最低录取位次（新高考省份核心参考指标）
- **示例值**：`1500`、`0`（老高考省份或数据缺失时为 0）
- **空值**：无空值，0 表示不适用或缺失
- **注意**：仅新高考改革省份有位次数据，老高考省份此字段为 0

#### min_section
- **类型**：STRING
- **含义**：最低分所在分数段（原始字符串）
- **示例值**：`'650'`、`'640-650'`
- **空值**：约 30% 为空

#### diff
- **类型**：INT
- **含义**：线差，即最低录取分数超出批次控制线的分数
- **示例值**：`50`（超出批次线 50 分）、`0`
- **空值**：无空值，0 可能表示数据缺失或恰好等于批次线

---

### 招生计划字段

#### lq_num
- **类型**：STRING
- **含义**：录取人数（计划招生人数）
- **示例值**：`'5'`、`'10'`、`''`
- **空值**：约 30% 为空字符串
- **注意**：存储为字符串，使用时需转换为数字

---

### 专业组与选科字段

#### sp_info
- **类型**：STRING
- **含义**：专业详细说明
- **示例值**：`'含实验班，毕业授工学学位'`
- **空值**：约 70% 为空

#### sp_type
- **类型**：STRING
- **含义**：专业类型标识
- **示例值**：`'1'`、`'2'`
- **空值**：约 50% 为空

#### special_group
- **类型**：STRING
- **含义**：专业组编号
- **示例值**：`'01'`、`'02'`
- **空值**：约 40% 为空，不分专业组时为空

#### first_km
- **类型**：STRING
- **含义**：首选科目要求（新高考 3+1+2 模式）
- **示例值**：`'物理'`、`'历史'`、`'物理或历史'`、`''`（不限）
- **空值**：约 50% 为空，老高考省份此字段无意义

#### is_score_range
- **类型**：STRING
- **含义**：是否为分数段数据标识
- **示例值**：`'0'`、`'1'`
- **空值**：约 30% 为空

#### min_range
- **类型**：STRING
- **含义**：最低分数段范围描述
- **示例值**：`'640-650'`
- **空值**：约 80% 为空

#### min_rank_range
- **类型**：STRING
- **含义**：最低位次范围描述
- **示例值**：`'1000-2000'`
- **空值**：约 80% 为空

#### sg_name
- **类型**：STRING
- **含义**：专业组完整名称
- **示例值**：`'理工类专业组（第一组）'`
- **空值**：约 40% 为空

#### sg_info
- **类型**：STRING
- **含义**：专业组说明信息
- **示例值**：`'本组含计算机、电子等专业'`
- **空值**：约 70% 为空

#### sg_xuanke
- **类型**：STRING
- **含义**：专业组选科要求（再选科目）
- **示例值**：`'化学'`、`'化学和生物'`、`'不限'`
- **空值**：约 50% 为空，老高考省份无此字段

---

## 常用过滤条件

```sql
-- 过滤无效分数数据
WHERE min_score > 0

-- 只看普通类招生
WHERE zslx_name = '普通类'

-- 新高考省份（有位次数据）
WHERE min_rank > 0

-- 指定首选科目（新高考）
WHERE first_km IN ('物理', '物理或历史', '')
```

## 数据质量总结

| 字段 | 数据完整性 | 说明 |
|------|-----------|------|
| school_id / province_id / year | 100% | 核心维度，无缺失 |
| spname（专业名称） | >99% | 极少缺失 |
| min_score（最低分） | ~85% | 0 表示缺失 |
| min_rank（最低位次） | ~50% | 仅新高考省份有效 |
| average_score（平均分） | ~60% | 部分省份不提供 |
| level1_name（学科门类） | ~80% | 少量缺失 |
| sg_xuanke（选科要求） | ~50% | 仅新高考省份有效 |
